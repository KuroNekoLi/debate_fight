【一、空雨傘（McKinsey）】

- 空（Fact）：研究 / 論文：人力資本理論指出新手可用較低初始報酬換取技能積累。；統計資料：新進、轉職、身障與中高齡重返者的起步生產力通常較低。；現象觀察：很多人願意先求有工作，再求薪資提升，但制度不允許。
- 雨（Interpretation）：這代表此座標下的核心問題是「契約禁制」，也就是 法律把原本可存在的「低薪但可累積經驗」工作一刀切為非法，讓勞工連自主交換都無法進行。
- 傘（Claim）：是，應廢除。

【二、需根解損（政策分析）】

- 需（Need）：存在，因為本單位所處理的核心議題是「最低工資法在治理上是否阻礙弱勢者進場？」，而具體問題表現為：法律把原本可存在的「低薪但可累積經驗」工作一刀切為非法，讓勞工連自主交換都無法進行。
- 根（Root）：契約禁制；其機制本質是：法制把低於底線的契約全部視為無效，等於以國家力量替雇主刪掉部分低門檻職缺。
- 解（Solve）：透過廢除最低工資法，移除由法定底線造成的限制，讓該座標下的交易與配置恢復彈性，並把弱勢保護改由更精準工具承接。
- 損（Trade-off）：代價在於 反方可說這會放任剝削；本論點的整體損益比評估為高。

【五、因果削弱與致命漏洞】

- ① 一因多果（A未必造成B / 解決力）：
  - 說明：就算法律禁止低於底薪的契約，也不代表原本那些工作一定會在廢法後重新出現；雇主可能仍因訓練成本、管理風險、客訴風險而不願聘用低熟練者。
  - 具體替代例子：早餐店不收中高齡轉職者，可能是怕尖峰時段帶教拖慢出餐，而不是單純因為不能用較低薪試用。
  - 最致命漏洞：如果低門檻職缺消失的主因是訓練成本與營運節奏，不是底薪禁制，那廢除最低工資對增加進場機會的解決力會被大幅削弱。

- ② 一果多因（沒有A也有B / 根屬性）：
  - 說明：弱勢者無法進場，不一定是契約被法律禁止，也可能是職缺本身減少、履歷篩選自動化、雇主歧視、交通距離或照護負擔造成。
  - 具體替代例子：身障求職者投遞門市工作被拒，可能是無障礙環境不足或排班不彈性，而不是薪資底線太高。
  - 最致命漏洞：如果對方能把排除現象導向歧視、職缺配置或訓練不足，你把根因鎖定為「契約禁制」就會顯得過窄。

- ③ B不重要（需要性）：
  - 說明：即使底薪確實阻斷部分低薪學習型工作，反方仍可說社會不應承認過低薪契約，真正需要的是補貼訓練與學徒制度，而不是讓弱勢自行降價求職。
  - 具體替代例子：政府可補助企業帶新人，或設有薪訓練期與明確期限，而不是允許任何低於底線的私人契約。
  - 最致命漏洞：如果你無法說明「低薪自主交換」比「受規範的訓練例外」更必要，這個論點會被打成把剝削包裝成選擇。

【五、論證鏈詳述（500字以上）】

正方在這裡要講的，不是「大家都應該低薪工作」，而是有些人連第一個入口都被制度封住了。想像一個剛轉職的人，原本願意先到小店做助理，薪水低一點沒關係，重點是有人願意教、願意讓他累積履歷。可是最低工資法把低於底線的契約一律打成非法，小店老闆就會開始想：既然我付出去的錢跟熟手差不多，那我為什麼要請一個還要教的人？最後不是新手拿到更好薪水，而是新手根本沒有被錄用。

這就是「契約禁制」的問題。法律看起來是在幫勞工擋住低薪，但它也同時擋掉一批低門檻、可訓練、可過渡的工作。對身障者、中高齡重返者、久未就業者來說，第一份工作常常不是終點，而是重新進入市場的踏板。反方當然可以說低薪會變剝削，這個提醒有道理，所以真正需要的是有期限、有訓練內容、有申訴保障的過渡制度。可是如果法律完全不允許這種交換存在，就等於國家替雇主把最弱的求職者先刪掉。這不是保護弱者，而是讓弱者連談判的門都進不去。

因此這個論點的重心，不是替低薪辯護，而是替「第一步」辯護。正方可以承認需要防剝削，但要逼反方回答：如果每一種低於底線的過渡安排都被禁止，那些還沒準備好、還不夠熟、還需要被帶的人，到底要從哪裡開始？只要反方答不出這個入口問題，廢除或大幅鬆動最低工資就有其必要性。

【五、論證鏈詳述（500字以上）】

反方要提醒的是，初入職場的人不是站在平等桌子上談薪水。很多剛畢業的人第一次面試，根本不知道行情是多少；老闆說「我們這行新人都這樣」，他也很難判斷是真是假。更弱勢的人更麻煩，像急著付房租的人、家裡需要他馬上拿錢回去的人，常常不是自由選擇，而是沒有本錢拒絕。這時候如果沒有一條法定底線，所謂契約自由很容易變成強者開價、弱者吞下去。

最低工資的價值就在這裡：它不需要新人懂法律、不需要他會談判，也不需要他敢跟老闆吵。只要低於這個數字，就是不可以。像實習、試用、學徒這些名目，本來就很容易被拿來包裝低薪；如果沒有底線，雇主只要說「你是在學習」就能把風險丟給新人。正方可以說用資訊揭露、反詐欺、補貼也能處理，但那些工具常常要申請、要舉證、要知道自己被騙。底薪比較笨，但它直接。對第一次進場的人來說，最重要的有時不是制度多精緻，而是至少有一條看得懂、用得上的防線。

所以這個論點最有力的地方，是把「自由契約」拉回現實。對一個完全不知道行情的新手來說，能不能拒絕不是抽象問題，而是今天有沒有錢吃飯、下個月能不能繳房租。最低工資未必精準，但它先把最誇張的低價排除掉，讓新人不用靠勇氣和法律知識去換基本待遇。

也因此，這段要用生活壓力來說服，而不是只講制度名稱。

  - 說明：即使替代制度較複雜，正方可說政策評估應看效果與副作用，不是只選最簡單的工具。
  - 具體替代例子：所得稅、健保補助、租金補貼都比底薪複雜，但若能更精準打到需要者，複雜性可以被接受。
  - 最致命漏洞：如果你無法證明簡單底線的淨效果優於複雜替代方案，替代治理成本只能當配套提醒，不能決定勝負。

【五、論證鏈詳述（500字以上）】

反方在這裡要把正方的替代方案拉回現實。廢除最低工資聽起來可以改用更精準工具，但精準通常代表更複雜。誰算弱勢？補貼多少？怎麼防止雇主吸收？什麼叫惡性低薪？個案要誰審？這些問題每一個都要行政人力、資料系統和申訴程序，不是喊一句「改用補貼」就會自動完成。

最低工資的好處不是最完美，而是簡單、清楚、立即生效。雇主知道底線，勞工知道底線，政府也知道怎麼查。正方會說，只要效果更好，複雜性可以接受；這句話也對，因為政策不能只選簡單的。可是反方要問的是：在替代制度還沒完整建好以前，拿掉底薪會不會先留下空洞？像補貼漏接、個案審查拖延、反剝削認定太難，都可能讓弱勢者等不到保護。最低工資至少是一張現有的底網。若要拆，正方必須證明新網已經織好，而且真的接得住人；否則所謂精準改革，可能只是把清楚底線換成一堆難用程序。

因此反方的攻法很明確：不是拒絕改革，而是要求正方交代過渡。若正方說用補貼，就要問財源和資格；說用反剝削法，就要問認定和舉證；說用集體協商，就要問低薪勞工有沒有組織能力。只要這些還沒準備好，最低工資雖然粗，仍是一個立即存在、所有人都懂的底層保護。

所以本段的勝負點，是正方替代方案能不能立刻接住人。
